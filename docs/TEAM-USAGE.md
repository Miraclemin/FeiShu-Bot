# 创建者配置，成员使用

工作台机器人允许已识别的用户私聊使用；在创建者已启用的群内，所有成员均可使用，是否需要 @ 仍遵循群设置。新群默认不启用。

工作台配置、账号、工作目录、重连、退出和会议加入/离开等管理命令只允许创建者。旧 admins 名单不再赋予工作台管理权。非工作台 CLI 配置保留原有规则。

会中收到的明确 @ 提问可由任意参会人触发，并记录实际发送者（若平台提供）。不会把参会人伪装成创建者。字幕仍只作为上下文，不自动触发任务。自动会后纪要遵循创建者设置。

群成员可通过 /meeting ask、notes、transcript 查询从本群加入的会议。非创建者不能从私聊或其他群按会议号读取会议资料；可直接在会中提问。

成员共享创建者配置的机器人能力与执行权限，不自动获得各自飞书账号身份。资料链接和工作目录不是严格的数据访问隔离。旧严格文档白名单和严格技能隔离仍拒绝执行，直到有可强制执行的隔离机制。

验证：权限策略、会议逻辑和命令集成测试；桌面程序更新重启后才加载新规则。两位真实飞书用户的现场验证需另行完成。

## 查询本群配置

权限申请清单按机器人保存在本机 `profiles/<profile>/permission-draft.json`，关闭页面或重启后保留。它只保存待申请项，不开通、不撤销飞书权限，也不代表授权状态；实际权限入口单独展示。更换绑定应用后不复用旧应用的清单。旧版从未保存过的选择无法恢复，需要首次重新选择。

`/status`、`/help`、`/usage` 显示本群角色、项目、个性化要求、Skills 名称与说明，以及已配置资料链接。清单每页 8 项，通过 `/status 2` 翻页。私聊不会列出其他群配置。查询不读取远程资料，因此标注“本次未验证访问权限”。

## 严格资料范围的后续方案（尚未实现）

每群维护资源 ID 和允许操作，由工具服务根据可信群身份逐次校验。知识库节点、表格和附件解析后要校验实际目标；搜索和读写都受限制。凭据由服务持有，Agent 不能读取凭据或绕过服务直接调用接口；执行环境还需要限制网络、主机文件和跨群缓存。提示词、Skills 说明和工作目录不能替代这些限制。
