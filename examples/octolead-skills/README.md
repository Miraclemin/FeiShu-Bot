# OctoLead Skill examples

Sanitized snapshots of the four reviewed workflows. These are reference material, not automatically installed bundled Skills. Replace placeholders with your own explicitly authorized project configuration. Legacy scheduling scripts referenced by these documents are not shipped here; desktop group queries use the injected group resources and current bot identity through lark-cli. Historical authorizations do not grant access to another installation.

Each Skill and its reference documents share `references/context.md`: desktop group configuration takes precedence; read-only table queries do not require a repository or project name; fixed-role legacy scripts must not switch the current identity.
